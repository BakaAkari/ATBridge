ATBridge Fab Companion 隐私说明

草案 · 2026-11-11 · 适用于扩展 0.2.0。发布前需由维护者确认并托管到公开 HTTPS 地址。

用途与数据流

本扩展把用户在 Blender 发起的搜索、资产选择与下载请求交给 Fab 网站，并把结果和文件路径交回本机 Blender。搜索词、资产标识、拥有状态、文件名称与大小、临时下载链接、配对令牌和本地路径仅用于完成这些功能。

Fab 请求使用浏览器现有登录会话。扩展不读取或导出 Cookie，不要求用户在扩展中输入 Epic 密码；浏览器仍会按 Fab 的规则随请求发送所需会话凭据。Fab 和其下载服务按各自隐私政策处理请求。

本机处理与保存

配对票据和令牌保存在运行中的页面及 Blender 服务内存，不保存为长期授权。配对需在 Blender 核对确认码并批准，停止服务或重新配对使旧授权失效。会话任务信息保留至 Blender 服务关闭。

ZIP 保存于 Chrome 下载目录的 ATBridge 子目录，校验后的副本与导入文件保存在 Blender 配置的缓存目录。Chrome 自身可能保留下载记录。卸载扩展不会删除这些文件；用户可使用 Chrome 下载管理和文件管理器清理。本扩展仅按自己创建的下载 ID 查询进度，不枚举全部下载历史。

共享、统计与权限

没有开发者遥测、广告或分析服务器；不销售用户数据，不为广告或与上述用途无关的目的共享数据。仅与 Fab 及其资产下载服务通信，以及向用户批准的本机 Blender 服务传输结果。扩展需要 Fab 页面脚本执行、Chrome 下载管理和本机通信权限。

控制与撤销

可以拒绝配对、断开连接、关闭扩展页面、停止 Blender 服务或卸载扩展。断开会尝试取消当前下载；已完成的文件保留。网站登录状态由 Fab 管理，注销账户应在官方网站完成。
