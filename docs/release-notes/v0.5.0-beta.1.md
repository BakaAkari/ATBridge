## 下载哪个包 / Which file

| 文件 / File | 适用 / For |
|---|---|
| `ATBridge_v0.5.0-beta.1_windows-x64.zip` | Windows：完整功能，含 Fab 独立浏览器（无需另装 .NET） / Windows, full features incl. the built-in Fab browser (no .NET install needed) |
| `ATBridge_v0.5.0-beta.1.zip` | macOS / Linux，或不需要独立浏览器 / macOS, Linux, or without the built-in browser |
| `SHA256SUMS.txt` | 校验值 / checksums |

安装：Blender → 编辑 → 偏好设置 → 插件 → 从磁盘安装，选择 ZIP（不用解压）。从旧版本升级请先移除旧版并重启 Blender。需要 Blender 4.2 或更高版本。
Install: Blender → Edit → Preferences → Add-ons → Install from Disk, pick the ZIP (don't extract). When upgrading, remove the old version and restart Blender first. Requires Blender 4.2+.

## 新增 / New
- **Fab 独立浏览器（Windows）**：在 ATBridge 自带窗口里登录 Fab、浏览 Megascans 并下载，带下载面板和商品预览图，不再需要浏览器扩展。
  **Fab browser (Windows)**: sign in, browse Megascans and download in ATBridge's own window with a download panel and product images; no browser extension needed.
- **资产收件区**：自动发现下载的资产 ZIP，显示名称、格式、分辨率和预览，一键导入；保留导入记录，可定位导入的对象。
  **Asset inbox**: finds downloaded ZIPs, shows name, format, resolution and preview, imports in one click, keeps history and can locate imported objects.
- **中英界面**，跟随 Blender 语言。 / **Chinese & English UI**, following Blender's language.

## 改进 / Improved
- 本地 ZIP 导入不再需要预先设置解压目录，ZIP 改名后仍能识别。 / Local ZIP import needs no extraction folder setup; renamed ZIPs are still recognised.
- 无法完整导入的包（如 Alembic）会在导入前明确提示。 / Packages that can't be imported fully (e.g. Alembic) are rejected up front with a reason.

## 修复 / Fixed
- Blender 5.x 下 OBJ 资产无法导入。 / OBJ assets failed to import in Blender 5.x.
- 开启中文数据名称翻译时材质构建失败。 / Material setup failed with translated (Chinese) data names.
- 多个 Principled BSDF 时贴图接到无输出的节点。 / Textures were linked to an unused Principled BSDF when several existed.

## 移除 / Removed
- Chrome 扩展配对方案（已由独立浏览器替代）和 3D 视图顶部重复的导入按钮。 / The Chrome extension companion (replaced by the built-in browser) and the duplicate import button in the 3D Viewport header.

## 已知限制 / Known limitations
- 独立浏览器仅支持 Windows；macOS / Linux 请用系统浏览器下载后导入。 / The built-in browser is Windows-only; on macOS / Linux download in your browser and import.
- 暂不支持 Alembic 包和单个 ZIP 内多个资产。 / Alembic packages and multi-asset ZIPs aren't supported yet.

测试环境 / Tested: Windows 11, Blender 4.2.10 LTS & 5.2.3 LTS.
