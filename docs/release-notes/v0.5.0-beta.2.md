## 下载哪个包 / Which file

| 文件 / File | 适用 / For |
|---|---|
| `ATBridge_v0.5.0-beta.2_windows-x64.zip` | Windows：完整功能，含 Fab 独立浏览器（无需另装 .NET） / Windows, full features incl. the built-in Fab browser (no .NET install needed) |

安装：Blender → 编辑 → 偏好设置 → 插件 → 从磁盘安装，选择 ZIP（不用解压）。从旧版本升级请先移除旧版并重启 Blender。需要 Blender 4.2 或更高版本。
Install: Blender → Edit → Preferences → Add-ons → Install from Disk, pick the ZIP (don't extract). When upgrading, remove the old version and restart Blender first. Requires Blender 4.2+.

## 新增 / New
- **Fab 资产全覆盖**：支持 FBX、OBJ 和 glTF 包。 / **Full Fab asset coverage**: FBX, OBJ and glTF packages.
  - 3D 资产：模型和材质。 / 3D assets: model and material.
  - 植物：每个变体导入一个模型并排开；叶片按不透明度镂空并透光。 / Plants: one model per variant, laid out side by side; leaves are cut out by opacity and let light through.
  - 表面、贴花、图集、瑕疵：有选中物体时替换它的当前材质槽，否则按真实扫描尺寸建平面。 / Surfaces, decals, atlases, imperfections: applied to the selected object's active slot, or to a plane at the real scanned size.
  - 笔刷：导入为图像纹理和纹理绘制笔刷。 / Brushes: imported as an image texture and a texture-paint brush.
- **下载品质提示**：收件区发现 Low/Medium 品质或只有 1K/2K 贴图的包时，建议改下更高品质。 / **Download quality hint**: the inbox suggests a higher tier for Low/Medium downloads or 1K/2K texture packs.

## 改进 / Improved
- **材质节点排布**：按通道分组、对齐、不重叠。 / **Material node layout**: grouped by channel, aligned, no overlaps.
- 重新导入到已有材质时，你加的节点、连线和静音状态都会保留。 / Re-importing onto an existing material keeps your nodes, links and muted state.
- 清理模型文件带来的残留材质、图片和孤立网格。 / Leftover materials, images and orphan meshes from model files are cleaned up.
- 只导入最高精度的 LOD0；多分辨率包默认最高使用 4K 贴图。 / Only LOD0 is imported; multi-resolution packs are capped at 4K by default.
- 置换强度使用资产的真实高度。 / Displacement strength uses the asset's real height.
- 侧栏中文说明不再被截断。 / Long sidebar text no longer gets cut off.

## 已知限制 / Known limitations
- **Megascans 树木**只提供 Unreal Engine 格式且许可限定 UE，无法导入。可用 Sapling Tree Gen 或几何节点生成树，再用 Megascans 树皮和叶片图集做材质。 / **Megascans trees** ship only in Unreal Engine format, licensed for UE only, so they can't be imported. Generate trees with Sapling Tree Gen or Geometry Nodes and use Megascans bark and leaf atlases instead.
- 只含 Alembic、USD 或 .blend 的包，以及单个 ZIP 内多个资产，暂不支持。 / Packages with only Alembic, USD or .blend, and multi-asset ZIPs, aren't supported yet.
- 独立浏览器仅支持 Windows；macOS / Linux 请用系统浏览器下载后导入。 / The built-in browser is Windows-only.
