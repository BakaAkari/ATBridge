## 下载与安装 / Download and install

- **Windows 完整包 / Windows full package**：`ATBridge_v0.5.0-beta.3_windows-x64.zip`，包含 Fab 独立浏览器，无需另装 .NET。 / Includes the Fab browser; no separate .NET install required.
- **通用包 / Other platforms**：`ATBridge_v0.5.0-beta.3.zip`，macOS / Linux 使用系统浏览器。 / macOS and Linux use the system browser.
- `SHA256SUMS.txt`：校验值 / checksums.

需要 Blender 4.2+。升级前关闭独立浏览器，移除旧版并重启 Blender，然后从偏好设置的“从磁盘安装”选择 ZIP，不用解压。
Requires Blender 4.2+. Close the Fab browser, remove the previous add-on and restart Blender, then use Install from Disk in Preferences to select the ZIP without extracting it.

## 本次更新 / Changes

- **N 面板工作台**：顶部切换“浏览 / 资产 / 设置”。资产栏突出预览和导入，下载与缓存选项集中到设置栏。 / **N-panel workspace**: Browse, Asset and Settings tabs separate discovery, import and configuration.
- **资产详情更紧凑**：缩短列表，缺图时移除大片空白；有商品关联记录时可打开对应商品页。 / **Compact asset details**: a shorter list, no large empty image area, and a product-page action when a cached association is available.
- **工具与物理模拟分组**：网格处理、场景维护分组排布；物理模拟独立折叠，碰撞体和高级参数分别收纳。 / **Organized tools and physics**: mesh and scene tools are grouped; physics has a separate collapsible panel with collider and advanced settings sections.
- **下载后页面误报失败**：修正 ZIP 下载中止页面导航时被错误面板遮盖的问题。 / **Download navigation fix**: attachment navigation no longer incorrectly covers the existing page with a load-error panel.
- **商品图缓存改进**：子窗口读不到商品信息时读取主窗口，保留同一商品页已读取的包名，并支持官方分享图作为后备来源。仍核对资产 ID 后才关联。 / **Product-image cache improvements**: fall back to the main window, retain package names for the same listing, and use the official social image as a fallback. Asset IDs are still checked before association.

## 测试与限制 / Testing and limitations

本次已完成 Blender 5.2.3 收件箱冒烟检查、面板绘制路径与中英文检查，以及相关缓存测试和本地浏览器下载测试。Fab 登录后的真实下载、商品图补齐和升级安装留待手动验证，尚未重新跑完整双版本回归。
This update passed the Blender 5.2.3 inbox smoke check, panel draw-path and language checks, related cache tests and a local browser download probe. Live Fab downloads, image recovery and upgrade installation await manual testing; the full two-version regression was not repeated.

商品图需能从商品页读取有效信息并匹配资产包；无法关联时仍可正常导入。独立浏览器仅限 Windows。资产格式支持范围沿用 beta.2。
Product images require readable listing data and a matching package; a missing image does not prevent import. The built-in browser is Windows-only. Supported asset formats are unchanged from beta.2.
