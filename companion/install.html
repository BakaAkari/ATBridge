连接 Blender 与 Fab

当前为测试版，尚未上架 Chrome 商店。正式版商店入口会在可用后显示于 Blender。

1. 安装 Chrome 扩展（仅首次）

  1. 在 Blender 的 ATBridge → Fab Companion 点击“打开扩展文件夹”。
  2. 在 Chrome 地址栏输入 chrome://extensions。
  3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择刚才的 extension 文件夹。
  4. 点击 Chrome 工具栏的扩展菜单，打开 ATBridge Fab Companion。建议固定到工具栏。

本地测试版更新后，在扩展管理页点击重新加载，再重新打开连接页。请保留该文件夹。

2. 连接 Blender（无需复制配对码）

  1. 在 Blender 点击“连接 Fab / 开启配对”。
  2. 在 Chrome 扩展页点击“请求连接 Blender”。
  3. 核对两边六位确认码，在 Blender 点击“允许连接”。配对窗口有效两分钟。
  4. 在扩展页点击“打开 Fab 登录”；已登录可直接回到 Blender 搜索。

请保持扩展连接页和 Fab 标签页打开。无需导出 Cookie，也无需安装本机宿主。

连接失败或已过期

在 Blender 点击“重新配对（取消当前任务）”，然后在扩展页重新请求连接。旧连接会失效。重新打开 Blender 或扩展页后需要重新配对；当前版本不长期保存浏览器授权。

若 Chrome 使用非默认下载目录，请在 Blender 启动连接前填写相同目录。只有完成校验的文件才能手动导入。Fab 要求重新登录或验证时，请在官方网站完成后手动重试。

功能范围：已拥有资产的 FBX ZIP，最高 1 GiB；当前导入主要支持带 Megascans 元数据的资产。不会购买、领取或接受许可。不隶属于 Epic Games、Fab 或 Blender。
